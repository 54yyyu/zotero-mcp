---
title: Windows fixes, and full PDFs from {repositories}
date: Oct 2026
---
On Windows, Claude Desktop no longer shuts the server down at startup when the semantic index updates on start: the update now runs as a separate process, so the server answers right away. The Zotero Agent plugin now finds Claude Code, Codex and pi on Windows, and installed copies update themselves. Translating with pi is not available there yet. Windows support for the plugin is new, so reports on [#700](https://github.com/54yyyu/zotero-mcp/issues/700) help.

Adding a paper by DOI now also tries the repository copies OpenAlex lists, after Unpaywall and before the publisher's page, and a publisher PDF that is only a short preview is skipped for the next source. Semantic search is its own tool group, on by default and left out when the `[semantic]` extra isn't installed; `ZOTERO_MCP_TOOLSETS=none` now leaves it out too, so use `none,semantic` to keep it. In local mode the duplicate check reads the DOI from `zotero.sqlite`, so a batch import no longer holds Zotero at full CPU for minutes. Markdown and YAML files can be attached, and their text is indexed.

> If you built an index with `gemini-embedding-2`, rebuild it with `update-db --force-rebuild`: it stored one vector per batch instead of one per item. With fixes from @phil-c137 (#708), @mronkko (#705), @falcon1-1-code (#689, #693 to #695), @lots-o (#698, #699), @RizgarOzan (#696) and @kskszq (#707).
