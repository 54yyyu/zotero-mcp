---
title: Half the context, {faster} batch edits, and auth for HTTP
date: Nov 2026
---
The MCP server's default tools now cost about 8k tokens per request instead of 17k. Descriptions are rewritten to what an agent needs to pick the tool, schemas are compact, and a test keeps the total from creeping back. `zotero_search_items` takes tags directly and `zotero_manage_collection` replaces three collection tools; the old names stay available for one release with `ZOTERO_MCP_TOOLSETS=default,legacy`. `zotero_add_item` now reuses an item it already has instead of adding a duplicate.

Batch tag and Extra edits take about 40 requests for 1000 items instead of 2000, and `zotero-cli` commands start in under half the time. In local mode more reads come straight from `zotero.sqlite`: whole-library annotations and notes, page layouts, the duplicate scan (no 5,000 item cap) and the Scite tools. The HTTP transports take a bearer token (`ZOTERO_MCP_AUTH_TOKEN`) and refuse to listen on the network without one. Semantic search notes when the index is behind the library, stops cleanly when the embedding API can't be reached, and no longer submits the same Batch API changes twice. In the Zotero Agent panel, a resized area now sends the new picture.

> Tool names changed: if a client or prompt calls `zotero_search_by_tag` or the collection tools by name, switch to the new ones or turn on the `legacy` group.
