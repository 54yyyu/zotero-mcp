0.12.5Sep 2026

Search finds the titles it used to miss

Keyword search on the SQLite backend looked up the title, date and journal by a fixed field id, so cases, statutes, webpages and some upgraded databases were skipped or listed as “Untitled”. Fields are now resolved per item type, the way Zotero does it, and the lookup costs less than the old one.

Collection-scoped search works again on the web API, annotations show their own text instead of “Untitled”, zotero_find_related_papers reports citation counts again, and BibTeX export works. update-db --limit no longer marks the whole library as indexed, and the ChatGPT connector falls back to keyword search when there is no semantic index.

Keyword search
1.3 msbefore: 3.6 ms

Measured on a 700-item library. If you have run update-db --limit, run update-db --fulltext once to repair the index.

Read and annotate a paper end to end

Reads flag the equations, figures and tables that text extraction garbles, and can return the page as an image. Highlights land on exactly the words asked for, and a whole reading plan is written in one batch.

Two ways in

An MCP server, or a skill for agents with a shell

Both use the same config. Use the MCP server when your client supports MCP but has no shell. Use the skill when your agent can run commands.

MCP server

For chat apps
  • Claude Desktop
  • ChatGPT
  • Cherry Studio
  • Chorus
  • Any MCP client

Your assistant gets Zotero tools for search, reading, annotations, and writes. Runs over stdio, or streamable HTTP for web clients.

$ zotero-mcp setup

Agent skill + zotero-cli

For coding agents
  • Claude Code
  • Cursor
  • Codex
  • Windsurf
  • Gemini CLI
  • Amp
  • OpenCode

The agent runs zotero-cli commands with --json. Its instructions only load when the task involves Zotero.

$ zotero-mcp install-skill

Connection

Local, web, or both

If Zotero is running on the same computer, you don’t need any credentials. Add a key when you want writes or access from somewhere else.

read → zotero.sqlite

Local, read-only

Reads from the Zotero app on your computer. Works offline.

Zotero running with the local API enabled, and ZOTERO_LOCAL=true
read + write → local

Local, read-write

Writes go to the running Zotero app too. No sync or Storage quota involved.

Zotero 10+, and zotero-mcp authorize-local once
read local · write web

Hybrid

Reads are local and fast, and writes go through the Zotero web API. Use this on Zotero 9 and older.

ZOTERO_API_KEY and ZOTERO_LIBRARY_ID alongside local mode
read + write → web

Capabilities

What it can do

The base install has no ML dependencies. Semantic search, PDF outlines, and Scite are optional extras.

Search

  • Keyword search, or conditions joined with AND/OR, including date ranges
  • Tag filters with OR and exclusions
  • Look up items by Better BibTeX citation key
  • Search your personal and group libraries at once

Semantic search

  • Find papers by meaning, with similarity scores
  • A free local embedding model, or OpenAI, Gemini, or Ollama
  • Optional passage-level chunking of full text
  • Batch embedding with the OpenAI and Gemini Batch APIs
Needs the [semantic] extra

Read

  • Metadata as Markdown, JSON, or BibTeX
  • Full text with the paper’s headings preserved
  • A PDF’s table of contents, then just the pages you need
  • Bibliographies formatted by Zotero’s own citation engine

Annotations and notes

  • Read, create, edit, and delete highlights
  • Area annotations placed on detected figures and tables
  • Create, update, and search notes
  • A per-paper summary of your highlights and notes

Add and organize

  • Add from a DOI, URL, ISBN, BibTeX, CSL JSON, or a local PDF or EPUB
  • Find open-access PDFs through Unpaywall, arXiv, Semantic Scholar, and PMC
  • Items already in your library are reused, not duplicated
  • Collections, bulk tag edits, and duplicate merging

Citations and discovery

  • Scite counts of supporting and contrasting citations, and retraction alerts (no account needed)
  • Find papers that cite, or are cited by, a work, via OpenAlex
  • See which items are missing a PDF
  • RSS feeds and related-item links
Optional tool groups, see Reference
Get started

Two commands to get going

Install the package, then run zotero-mcp setup. It configures Claude Desktop for you and prints the settings other clients need.

$ uv tool install "zotero-mcp-server[all]"
$ zotero-mcp setup

New to the command line? The community-built Zotero MCP Setup includes a macOS installer and one-click scripts for Mac and Windows.
